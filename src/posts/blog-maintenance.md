这个博客把文字内容和页面样式分开保存。写一篇新文章时，只需要新增一个 Markdown 文件；首页、列表和最近更新会在生成网页时自动整理。

## 一、先认清目录

- **文章**保存在 `src/posts/`。
- **旅行记录**保存在 `src/travel/`。
- **视频介绍**保存在 `src/videos/`，可以填写已准备好的视频文件地址。
- **公共页面模板**保存在 `src/_includes/`，导航与页脚统一维护。
- **博客名称和两位记录者的资料**保存在 `src/_data/site.json`。
- **生成后的网页**位于 `_site/`，可交给静态网站托管服务发布。

## 二、添加一篇文章

复制一份现有文章，使用简短的英文文件名，例如 `my-first-note.md`。文件开头两条 `---` 之间填写标题、日期、作者、分类和摘要，之后就是正文。

正文直接使用 Markdown：空行分段，使用井号添加标题，也可以插入图片与链接。修改公共样式时，编辑 `styles/style.css` 即可。

新增文章后，运行 `npm run build`。文章列表、总数、首页与最近更新会一起更新，不需要逐页补链接。

## 三、先预览，再发布

在仓库目录执行 `npm run dev`，打开终端给出的本地地址。保存文章后，预览会自动更新。

发布前执行 `npm run check`，生成网页并检查站内链接。需要交给托管平台的是生成后的 `_site/` 目录。

## 四、整理图片与视频

当前山景是沿用的站点配图，并不代表一篇已经完成的旅行经历。页面加载压缩后的图片，原始素材保留在仓库中，方便重新导出。

给新文章添加封面时，同时填写图片地址、说明、宽度和高度。正文图片的地址从当前文章页所在位置计算；放在 `images/` 下的图片可以通过 `../images/文件名` 引用。

视频栏目可以展示已准备好的视频链接和介绍。上传、登录、评论和 NAS 接入留待后续阶段配置。

## 五、关于草稿

把文章开头的 `draft` 设置为 `true`，它就不会生成公开页面，也不会出现在列表中。生成时会清理旧的网页文件，避免已转为草稿的内容残留在发布目录。

草稿文件仍保存在源码里；如果源码仓库公开，草稿本身也可以被查看。需要私密保存的记录应使用私有存储。

写作的方法会随着博客一起完善。先让每一篇记录都有自己的位置，再慢慢增加新的功能。
